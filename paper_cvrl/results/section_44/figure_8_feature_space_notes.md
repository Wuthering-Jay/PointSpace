## Final Fig. 8: PCA-color rendering

![PCA-color Fig. 8](figure_8_pca_rgb_frozen_representations.png)

The final manuscript figure is [`figure_8_pca_rgb_frozen_representations.png`](figure_8_pca_rgb_frozen_representations.png), with a matching [`PDF`](figure_8_pca_rgb_frozen_representations.pdf) and reproducibility [`metadata`](figure_8_pca_rgb_frozen_representations.json). The first row shows LAS semantic-label references. The other rows color **the same original ALS points** by frozen VPSD 128D, RRCL 72D, and CVRL 200D representations. None is a semantic prediction or a downstream-fine-tuned feature.

- Urban: `swisssurface3d_2024_2679-1248_2056_5728.copc_0033`, 314,477 points; the final 121.9 m long, 1.5 m wide A–A′ profile contains 5,870 points (2,200 ground, 966 vegetation, 2,044 roof, 422 facade, 238 unclassified). It crosses several complete roofs, ground between buildings, tree cover, and building edges. The earlier urban scene had a conspicuous VPSD roof-color discontinuity; the replacement scene has more continuous roof-color structure. Relative to the preceding A–A′ line, this line is translated 1 m west and 1 m south, while Forest remains unchanged.
- For profile selection only, a fixed green-hue diagnostic (`HSV hue 0.19–0.51`, saturation ≥0.30, value ≥0.18) identifies 1,348 LAS-ground points in the final A–A′ band, versus 1,381 in the immediately preceding band on the **same tile**; the new band includes more actual vegetation (966 versus 676 points). This threshold is not used for feature fitting, rendering, or a reported accuracy metric. “Green ground” means color similarity in a continuous feature visualization, **not** a semantic classifier predicting vegetation.
- Forest: `swisssurface3d_2023_2616-1179_2056_5728_0036`, 368,594 points; the 99.2 m long, 1.5 m wide B–B′ profile contains 5,492 points (748 ground and 4,744 vegetation). It crosses a more continuous canopy with ground returns below it. The VPSD profile shows local color overlap between low canopy and under-canopy ground, whereas the CVRL display shows a clearer layered pattern. These are qualitative observations, not measured occlusion-error rates.
- Scene selection was a two-stage display audit: first screen Swiss-Audit blocks for the required physical structures and the availability of aligned frozen features, then inspect candidate LAS-label reference maps before exporting full-point features. Sampled ground/roof or ground/vegetation feature separability was a diagnostic for avoiding a degenerate display, not a reported performance result. The chosen scenes are illustrative, not an unbiased estimate of dataset-wide behavior.
- VPSD and RRCL independently fit direct 3D PCA per region on 55,000 unlabeled, per-point L2-normalized features. The PCA fit and 1st/99th-percentile limits within one region are reused for its top view and vertical profile. Colors are **not comparable across regions or methods**.
- CVRL uses a protected, region-specific multi-view PCA display. Its visual and return slices are separately L2-normalized, reduced and whitened before a final joint 3D PCA. Urban retains `3V+1R` components with unit display gains. Forest retains `3V+3R` components and multiplies the whitened return scores by **1.35** before the final PCA. This is a forest-only visualization weight; it changes neither pretrained weights nor saved features. Colors remain comparable within one representation and region, not across regions.
- Clipped, unit-scaled PC1/PC2/PC3 receive a symmetric power contrast stretch (`gamma=0.72`). A weighted rigid Procrustes transform then rotates/reflects and translates the *whole* three-dimensional display embedding using sampled Reference class centroids. The orientation anchors approximate tan ground, green vegetation, warm red roof, and purple facade. All point colors are obtained by applying the same continuous transform; no point receives its semantic-label color. The operation preserves pairwise distances among stretched PCA coordinates before gamut clipping, but **uses LAS labels to orient the display**. Color agreement with Reference is therefore not independent evidence of semantic learning.
- The oriented coordinates map to CIELAB by `a*=75·q₁`, `b*=70·q₂`, `L*=61+19·q₃`, with display gamut clipping before sRGB conversion. Colors are only approximately aligned with the semantic legend; different methods and regions still have different fitted PCA bases and display transforms.
- Top views use the paper's NumPy PCV + edge-only EDL renderer, 128 PCV directions, 512-pixel PCV buffer, circular adaptive splats with point scale 0.86, and a fixed orthographic nadir view. Profiles have white backgrounds and thin grey grids. Each region uses identical points, camera, profile line, and extent across rows.

**Suggested caption.** Fig. 8. PCA-colored rendering of frozen visual, return, and complementary representations. Urban and forest Swiss-Audit regions are shown in top view and along 122 m and 99 m vertical profiles, respectively. The Reference row shows LAS semantic labels; the other rows show continuous colors derived from frozen VPSD, RRCL, and CVRL features at the same point positions. VPSD and RRCL use direct three-component PCA. CVRL uses protected branch-wise PCA followed by joint PCA: three visual and one return component are retained for Urban, while three components from each branch are retained for Forest; the whitened return scores receive a 1.35-fold display gain in Forest only. PCA is fitted separately for each region and representation without labels. For display only, a rigid rotation/reflection and translation of each three-dimensional PCA embedding is selected from sampled LAS class centroids to align its broad hues with the Reference palette. Every point is colored by the same continuous transform, without per-point label recoloring. The hue agreement with Reference therefore should not be interpreted as independent semantic evidence; frozen probe results provide that evidence. No downstream fine-tuning is used.

## KMeans counterpart (exploratory)

For each representation and region, KMeans with `K=8`, `n_init=5`, and seed 42 is fitted on 55,000 sampled original L2-normalized high-dimensional features; it then assigns every point. KMeans is **not fitted on PCA coordinates** and does not use semantic labels. Unlike the PCA display figure, CVRL KMeans uses the raw 200D feature without the protected two-stage display transform. Cluster IDs are ranked by cluster population only to stabilize the palette; the same hue across methods or regions has **no common semantic meaning**. This is a categorical cluster map, not a segmentation prediction.

## Interpretation and manuscript text

VPSD already shows clear large-scale roof and vegetation organization in the urban scene; it should not be described as wholly failing under occlusion. Along the revised urban profile, however, some LAS-ground points between buildings occupy a green feature-color range similar to vegetation, whereas the CVRL display gives those locations a more distinct hue while retaining coherent roof structure. In the forest profile, the more continuous canopy makes low-layer and ground color overlap in VPSD easier to inspect; RRCL and CVRL show stronger vertical variation. These are qualitative feature-color observations, **not semantic predictions or error-rate estimates**. The reference-oriented PCA palette makes structural patterns easier to inspect but cannot independently establish semantic separability because it uses class centroids for orientation. The Section 4.4 frozen-probe and pairing-control results carry the quantitative complementarity claim.
